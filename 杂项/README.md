# 杂项目录说明

本目录存放项目辅助文档与任务清单，**不是**可运行后端。

当前正式架构为：

- **后端**：Spring Boot（`../back-end`），默认端口 **9999**
- **前端**：Vue 3（`../frontend`），开发端口 **3000**

请勿再按旧版 Node.js `backend/server.js` 方式启动。

## 本目录文件

| 文件 | 说明 |
|------|------|
| `API-Documentation.md` | REST API 说明（基础 URL：`http://localhost:9999/api`） |
| `todolist.md` | 已知问题与改进清单 |
| `README.md` | 本说明 |

## 启动方式

见仓库根目录 [`README.md`](../README.md) 或执行 `../run-all.cmd`。
